# Research stage

Topic research is done live by the agent using:
- **Playwright MCP** (`playwright` server) — opens a real browser to browse pages, read articles, check trending topics/competitor videos.
- **WebSearch** tool — general web search for topic ideas, trends, keyword research.

Save research findings here as `<topic-slug>.md` (source links + key facts + angle ideas) so the script-generation stage can turn them into a video script.
